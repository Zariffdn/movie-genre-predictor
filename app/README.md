# Flutter app

The phone side of the project. See the [main README](../README.md) for the full picture and [STUDY.md](../STUDY.md) for a walkthrough.

```sh
flutter test   # tokenizer cases, Python parity, widget tests
flutter run    # on a connected phone or emulator
```

`assets/model.json` and `test/fixtures/parity_cases.json` are generated by `training/train.py`. Don't edit them by hand.
